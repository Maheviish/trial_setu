Compliance Framework & Staged Interoperability Roadmap

1. ALCOA+ Audit Trail Integrity (REAL / IMPLEMENTED)

Enforces all 9 ALCOA+ principles (Attributable, Legible, Contemporaneous, Original, Accurate, Complete, Consistent, Enduring, Available). All database mutations generate immutable audit logs with code-level protection preventing UPDATE or DELETE statements against the audit_logs table.

2. India Digital Personal Data Protection (DPDP) Act 2023 & 2025 Rules

Informed consent tracking complies with India's DPDP Act provisions. Clinical trials feature verifiable multi-lingual informed consent version histories, mandatory consent verification before randomization, and strict role-based data minimization.

3. ISO/IEC 27001 & CERT-In Guidelines

Server architecture implements scrypt password hashing (64-byte salts), HMAC-SHA256 session token signatures, and least-privilege server-side authorization filters. Certified hosting environments within Indian sovereign data residency are defined for production deployment.

4. CDISC & HL7 FHIR R4 Interoperability (Phase 2/3 Roadmap)

Accurately Scoped as Phase 2/3 Roadmap (Not Faked):
  • Phase 2: Automated CDISC pipeline converting trial CRFs to CDASH standards, mapping clinical domains to SDTM (AE, DM, LB, CM) and ADaM analytical datasets with Define-XML 2.1 packages.
  • Phase 3: HL7 FHIR R4 API integration with ABDM (Ayushman Bharat Digital Mission) and EHR/HIS hospital electronic registries for federated multi-centre safety signal ingestion.
